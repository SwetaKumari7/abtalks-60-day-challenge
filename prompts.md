## 1. Purpose of Using AI

AI was used as a development assistant during the hackathon to help with:

- Understanding the hackathon requirements
- Breaking the problem into smaller implementation steps
- Designing the mobile-first user interface
- Generating and improving React/TypeScript code
- Planning the three required routes
- Debugging routing and deployment issues
- Preparing the README and Route Map
- Preparing the AI usage documentation
- Checking the project against the hackathon requirements

The final project was tested manually in the browser and at a 390px mobile viewport.
